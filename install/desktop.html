🖥️ Install TokenOptim on Desktop

Load TokenOptim as a Chrome extension in developer mode (2 minutes)

1

Clone the Repository

Get the code from GitHub:

git clone https://github.com/adifydigitalnoida-del/tokenoptim

Or download as ZIP and extract it.

2

Open Chrome Extensions

Go to: chrome://extensions/

Or: Chrome menu → Settings → Extensions

3

Enable Developer Mode

Toggle "Developer mode" in the top right corner

4

Load Unpacked

Click "Load unpacked"

Select the tokenoptim folder (where you cloned/extracted it)

5

Done! 🎉

TokenOptim icon appears in your Chrome toolbar (top right)

Click it to open the popup

First Use

  1. Click the TokenOptim icon in your toolbar
  2. See the "Quick Counter" section at the top
  3. Paste any text and click "Count Tokens"
  4. See token count + estimated cost instantly

Troubleshooting

Extension won't load?

  • Check that the folder contains manifest.json
  • Make sure icons/ folder exists with PNG files
  • Refresh the page or toggle Developer Mode on/off

No token count showing?

  • Use the Quick Counter (paste text into popup)
  • Page-level integration coming in v3.2

Next Steps

Now that it's installed:

  1. Test the Quick Counter with a sample prompt
  2. Go to Claude.ai or ChatGPT
  3. Use TokenOptim to count tokens before sending
  4. See your cost savings in the stats dashboard
