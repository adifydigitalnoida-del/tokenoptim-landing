🏢 Enterprise Deployment

Self-hosted deployment with full control over your instance

Requirements

  • Node.js 16+ or Docker
  • Vercel, AWS, DigitalOcean, or any cloud provider
  • Git (to clone the repo)
1

Fork the Repository

Go to: https://github.com/adifydigitalnoida-del/tokenoptim

Click "Fork" in the top right

2

Clone Your Fork

git clone https://github.com/YOUR-USERNAME/tokenoptim
3

Choose Your Deployment Method

Option A: Vercel (Easiest)

  1. Go to vercel.com
  2. Click "New Project"
  3. Import your GitHub fork
  4. Deploy (automatic in 2 minutes)

Option B: Docker

docker build -t tokenoptim . && docker run -p 3000:3000 tokenoptim

Option C: Node.js

  1. npm install
  2. npm start
  3. Server runs on localhost:3000
4

Configure (Optional)

Set environment variables:

API_KEY=your_key
DATABASE_URL=your_db
NODE_ENV=production
5

Set Up SSO (Optional)

Connect to your organization's SSO:

  • Okta
  • Azure AD
  • Google Workspace

See docs/SSO.md for setup

6

Distribute to Team

Share your instance URL with your team

Configure MDM (Mobile Device Management) for extension distribution

Features (Enterprise)

  • ✅ Full data control (on your servers)
  • ✅ Zero telemetry/analytics
  • ✅ Custom branding
  • ✅ Team management & permissions
  • ✅ Audit logs
  • ✅ SAML/SSO integration
