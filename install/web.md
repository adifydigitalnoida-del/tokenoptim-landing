# TokenOptim Web (SaaS)

## No Installation. Just Sign Up.

1. **Go to:** https://tokenoptim.vercel.app/web
2. **Sign up** with GitHub/Google/Email (10 sec)
3. **Add your API key** (optional, to track real costs)
4. **Paste text** → Click "Count Tokens"
5. **See results:** Token count + cost instantly
