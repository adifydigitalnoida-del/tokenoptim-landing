# Install TokenOptim on Desktop

## 2-Minute Chrome Extension Setup

1. Go to: `chrome://extensions/`
2. Toggle "Developer mode" (top right)
3. Click "Load unpacked"
4. Select the `tokenoptim` folder (cloned from GitHub)
5. Done! Icon appears in toolbar

## First Use

- Click icon
- See "Quick Counter" section
- Paste text → Click "Count Tokens"
- See token count + cost instantly

## Troubleshooting

- Extension won't load? Make sure `manifest.json` exists in folder
- Missing icons? Check that `icons/` folder has PNG files
- Refresh page if it doesn't appear
